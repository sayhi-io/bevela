protocol documents add historical-status notices and replace private evidence links.

alongside curated result reports and an allowlisted measurement export. Raw native
conversations, credentials, runtime records, registrations, generated source copies,
caches and environments are excluded. Unrelated throughput UI work remains in its
own worktree. Original frozen experiment inputs and results are not rewritten.

change experiment source, execute another trial or supply a favorable result.
Source staging/publication is separate from runtime activation.
